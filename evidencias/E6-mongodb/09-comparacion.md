| Evento auditable                      | PostgreSQL (bitácora + disparador)                                     | MongoDB Community (perfilador + bitácora)                                                                                                                     | MongoDB Enterprise/Atlas (auditoría nativa)                                                                               |
| :------------------------------------ | :---------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| Acceso exitoso                        | Sí (observado)                                                         | Sí (observado en la bitácora bajo el componente ACCESS)                                                                                                      | Documentado, no practicado                                                                                                 |
| Acceso fallido                        | Sí (observado)                                                         | Sí (observado en la bitácora bajo el componente ACCESS)                                                                                                      | Documentado, no practicado                                                                                                 |
| Cambio de privilegios                 | Sí (observado)                                                         | Parcial (no existe registro nativo; solo es detectable mediante el control compensatorio de instantáneas periódicas, sin conocer el autor ni la hora exacta) | Documentado, no practicado                                                                                                 |
| Cambio de estructura                  | Sí (observado)                                                         | Parcial (visible únicamente si el perfilador está encendido y captura el comando ejecutado, pero no cuenta con auditoría DDL dedicada)                      | Documentado, no practicado                                                                                                 |
| Modificación de datos                | Sí (observado)                                                         | Parcial (requiere activar manualmente o por configuración el perfilador, el cual está sujeto a sobrescritura por el límite de 1 MB)                         | Documentado, no practicado (requiere habilitar auditAuthorizationSuccess: true)                                            |
| Valor anterior del dato               | Sí (observado mediante disparador y registro OLD)                      | No (el perfilador únicamente almacena la instrucción recibida, nunca el estado previo del documento)                                                         | Documentado, no practicado (la auditoría registra el evento y comando, pero no conserva el estado anterior del documento) |
| Lectura de datos sensibles            | Parcial (requiere log_statement = 'all', generando un volumen muy alto) | Parcial (solo visible con el perfilador en nivel 2 o filtro específico, con alto costo de rendimiento y riesgo de exponer datos en los filtros)               | Documentado, no practicado (requiere habilitar auditAuthorizationSuccess: true)                                            |
| Cambio de configuración del registro | Sí (observado)                                                         | Parcial (registra "Profiler settings changed" con un identificador de conexión ctx, requiriendo correlacionarlo con la autenticación previa en memoria)      | Documentado, no practicado                                                                                                 |
