
# LAB-03 — Políticas prácticas, gobierno de datos y evidencias

Aquí está el trabajo integrador de la Unidad III para la base **comercial**, tomando como base **PostgreSQL 16** y **MongoDB 7** (del LAB-02) para armar el expediente que pide auditoría interna[cite: 1, 2, 5].

## Qué hay en esta carpeta

* `EXPEDIENTE.md`: El expediente completo de auditoría interna con las 10 secciones que pide la práctica[cite: 25, 27].
* `sql/`: Los scripts SQL usados para revisar calidad (`01`), poner comentarios en columnas (`02`), listar tablas (`03`) y llevar el control de cambios (`04`)[cite: 8, 12, 14, 22, 27].
* `politicas/`: Las seis políticas prácticas (`POL-01` a `POL-06`) sobre acceso, respaldo, retención, restauración, datos sensibles y cambios en producción[cite: 16, 17, 18, 27].
* `evidencias/`: Los análisis de cada actividad (`01` a `06`), el CSV del diccionario, las exportaciones `E1` a `E5` con su hash y la carpeta `E6-mongodb/`[cite: 22, 23, 24, 27].
